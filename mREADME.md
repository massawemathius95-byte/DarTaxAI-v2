# DarFarePredictor

DarFarePredictor is a Streamlit-based application that predicts Uber fares in Dar es Salaam using machine learning models. It supports both single trip predictions and batch predictions via CSV, and it can use live GPS location for pickup points.

## Features
- Predict fares for a single trip with user-input or live GPS location.
- Batch fare predictions by uploading a CSV file.
- Automatic distance calculation between pickup and dropoff locations using the Haversine formula.
- Supports Linear Regression and Decision Tree models.
- User-friendly Streamlit interface.
